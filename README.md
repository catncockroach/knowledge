# Knowledge

Kho kiến thức cá nhân: các ghi chú nghiên cứu, học tập, viết bằng Markdown. Mỗi thư mục là một domain kiến thức.

## Thư mục

- [`data-analysis/`](data-analysis/README.md): kiến thức cơ sở về phân tích dữ liệu (thang đo, lấy mẫu, làm sạch, biến đổi, thống kê mô tả và suy luận, kiểm định, hồi quy, A/B test, chuỗi thời gian, funnel/cohort).
- [`enterprise-security/`](enterprise-security/README.md): kiến thức cơ sở về an ninh thông tin doanh nghiệp (rủi ro, tấn công, SIEM, SOC, detection engineering, incident response, SOAR/XDR).
- [`internet/`](internet/README.md): kiến thức cơ sở cốt lõi về mạng máy tính (các tầng OSI/TCP-IP, IP, routing, TCP/UDP, DNS, HTTP, bảo mật, công cụ chẩn đoán).
- [`research/`](research/): các báo cáo nghiên cứu theo từng đề tài, mỗi đề tài một thư mục `<YYYY-MM-DD>-<slug>/` gồm `brief.md`, `notes/` và `report.md`.
